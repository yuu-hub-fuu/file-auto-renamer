# 自动文件/文件夹改名器

一个面向邪恶重复命名（一切水课作业，公司资料命名） Windows 的拖拽式改名工具。

用户只需要下载 `exe`：

- 双击 `自动改名器.exe`：打开配置面板
- 把文件或文件夹拖到 `自动改名器.exe` 上：直接按规则改名

不需要安装 Python，不需要看命令行。

## 下载

推荐直接到 GitHub 的 `Releases` 页面下载最新版本的 `自动改名器.exe`。

如果你是仓库维护者，发布时把下面这个文件上传到 Release 附件即可：

- `dist/自动改名器.exe`

## 功能特点

- 支持文件和文件夹改名
- 支持直接拖拽到程序上使用
- 支持固定名字、前缀、后缀、高级自定义
- 控制面板支持直接选择文件/文件夹并立即改名（不必拖拽）
- 文件扩展名强制保留，不会被误改
- 一次处理多个项目时会先弹出确认框
- 配置会自动保存，下一次打开还能继续用

## 普通用户怎么用

### 1. 设置规则

双击 `自动改名器.exe`，会打开控制面板。

你可以直接选这些常见模式：

- 固定叫这个名字
- 在原名字前面加字
- 在原名字后面加字
- 高级自定义

设置好后点“保存配置”。

控制面板底部还可以直接点击：

- `选择文件并改名`
- `选择文件夹并改名`

可在不拖拽的情况下直接执行改名。

### 2. 开始改名

把文件或文件夹直接拖到 `自动改名器.exe` 上。

程序会按你刚才保存的规则自动改名。

如果一次拖了多个项目，会先弹出确认框，确认后才执行。

## 最常见的用法

### 固定名字

如果你想所有文件都改成同一个基础名字：

- 选择 `固定叫这个名字`
- 输入：`资料`

效果：

- 单个文件：`资料.txt`
- 多个文件：`资料_01.txt`、`资料_02.txt`

### 加前缀

如果你想保留原文件名，只在前面加字：

- 选择 `在原名字前面加字`
- 输入：`已处理_`

效果：

- `照片.jpg` -> `已处理_照片.jpg`

### 加后缀

如果你想保留原文件名，只在后面加字：

- 选择 `在原名字后面加字`
- 输入：`_备份`

效果：

- `照片.jpg` -> `照片_备份.jpg`

## 安全机制

- 文件后缀名始终保持原样，比如 `.txt` 不会被改成 `.jpg`
- 同一次处理多个文件时必须确认
- 不支持一次同时拖入父目录和它里面的子项目，避免误操作

## 高级自定义

如果你需要更灵活的规则，可以使用这些变量：

- `{input}`：你手动输入的内容
- `{name}`：原完整文件名
- `{stem}`：原文件名，不含后缀
- `{ext}`：原后缀名文本
- `{index}`：序号
- `{date}`：当前日期
- `{time}`：当前时间
- `{parent}`：父文件夹名

说明：

- `{ext}` 只是可引用文本，不会真的把文件后缀改掉
- 控制面板高级设置支持自定义日期/时间格式，以及重名处理策略（自动补号或报错）

## 开发者说明

如果你是项目维护者，本地开发主要文件如下：

- `rename_tool.pyw`：主入口，双击开配置，拖拽即改名
- `rename_core.py`：核心改名逻辑
- `rename_control.pyw`：控制面板入口
- `build_exe.bat`：打包脚本

## 本地运行

```powershell
python .\rename_tool.pyw
```

## 本地打包

```powershell
cmd /c build_exe.bat
```

打包完成后，成品在：

- `dist/自动改名器.exe`

## 发布建议

推荐发布方式：

1. 推送源码到 GitHub 仓库
2. 创建一个 GitHub Release
3. 上传 `dist/自动改名器.exe`
4. 在 Release 说明里写清楚“双击配置、拖拽改名”

## 注意事项

- 第一次运行时，Windows 可能会弹出安全提示，这是未签名程序的常见现象
- 当前主要面向 Windows 使用
- 如果杀毒软件拦截，请把程序放到普通可写目录后再试
